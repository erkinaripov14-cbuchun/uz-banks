    Reytinglar

    Har bir toifadagi eng yaxshi takliflar: omonatda yuqori foiz, kreditda past foiz yaxshi.

      Banklar bo'yicha tahlil

      Har bir bankning shu toifadagi eng yaxshi stavkasi. Ustuniga olib borsangiz, mahsulot nomi va shartlari chiqadi. Aniq raqamlar "Omonatlar" va "Kreditlar" jadvallarida.

      Administrator

      Hozir yangilash (token kerak emas)

      1. Quyidagi tugmani bosing — GitHub sahifasi ochiladi (GitHub hisobingizga kirgan bo'lishingiz kerak).
      2. O'ng tomondagi Run workflow ni bosing. Banklar maydonini bo'sh qoldiring (hamma banklar yangilanadi) va yashil Run workflow tugmasini bosing.
      3. 30–40 daqiqadan keyin bu sahifani qayta yuklang.
      GitHub'da yangilashni boshlash

      Bitta tugma bilan yangilash uchun sozlash (ixtiyoriy, bir marta)

      Saytdan yangilash uchun GitHub ruxsatnomasi (token) kerak. U faqat shu brauzerda, admin paroli bilan shifrlangan holda saqlanadi — saytga ham, repoga ham yuborilmaydi.

      1. GitHub'da yangi token yarating (Fine-grained token).
      2. Repository access: "Only select repositories" → uz-banks.
      3. Permissions → Actions: "Read and write". Boshqa ruxsat kerak emas.
      4. Tokenni nusxalab, quyiga qo'ying va saqlang.

      Bank saytlarini qayta o'qib, saytni yangilash. Jarayon 30–40 daqiqa davom etadi, keyin sahifani qayta yuklang.

      GitHub'da ko'rish

      Bu kod token admin paroli bilan shifrlangan holda. Uni saytga joylash uchun repo egasiga yuboring — shundan keyin har qanday qurilmada faqat parol va bitta tugma yetadi. Parolsiz bu koddan foydalanib bo'lmaydi.

      Stavkalar bank saytlaridan olingan, ayrim sahifalarda sana ko'rsatilmagan. Kredit foizi mijozga qarab belgilanadi. Bu sayt moliyaviy maslahat bermaydi: qaror qabul qilishdan oldin bankning o'zidan tekshiring.
